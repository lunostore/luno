# 📦 نظام الشحن اليدوي — Luno Store

تم إلغاء سكريبتات وأتمتة بايثون السابقة بناءً على طلبك والاعتماد بالكامل على **الشحن اليدوي** من لوحة التحكم.

### مميزات الشحن اليدوي الحالية:
1. إدخال رقم البوليصة / التتبع مباشرة من نافذة تفاصيل أي طلب في لوحة التحكم (`/admin/orders`).
2. تحويل حالة الطلب تلقائياً إلى **جارٍ الشحن** عند حفظ رقم البوليصة.
3. إمكانية نسخ رقم التتبع بنقرة واحدة وإرساله للعميل عبر الواتساب.
